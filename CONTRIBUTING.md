# Contributing

Thank you for helping improve this project.

1. Open an issue describing the bug, experiment, or proposed change.
2. Create a focused branch and keep unrelated changes separate.
3. Add or update tests for behavioral changes.
4. Run `pytest -q` before submitting a pull request.
5. Explain any effect on reproducibility or frozen artifact hashes.

Do not contribute private operator data, credentials, restricted datasets, proprietary documentation, or third-party model weights. Synthetic examples and properly licensed public data are welcome when their provenance is documented.

By contributing code, you agree that your contribution is licensed under the repository's MIT License. Contributions containing challenge data remain subject to CC BY-SA 4.0.
